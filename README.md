🛒 Amazon Clone

A front-end clone of Amazon’s homepage, built entirely with HTML & CSS.
This project focuses on practicing responsive layouts, CSS styling, and UI design without using JavaScript or backend logic.

✨ Features

✅ Static Amazon-like homepage

✅ Header with logo, search bar, and navigation links

✅ Product grid with cards

✅ Footer with useful links

✅ Responsive design using flexbox and grid
